# HR Portal - Three Tier Application

## Architecture
- **Frontend**: Static HTML
- **Backend**: Python Flask Gunicorn
- **Database**: SQLite

## Setup

1. Install Python dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
python app.py
```

Access at: http://localhost:5000

## Features
- View all employees
- Add new employees
- Delete employees
